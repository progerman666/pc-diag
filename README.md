# pc-diag

Агент-диагност Windows: собирает данные о системе (read-only), находит
проблемы по правилам и (опционально) объясняет их через Claude.

## Установка

    python -m venv .venv
    .\.venv\Scripts\Activate.ps1
    pip install -r requirements.txt

## Запуск

Без LLM (только правила и данные):

    python -m diag --no-llm

С LLM (нужен ANTHROPIC_API_KEY в .env):

    python -m diag

С сохранением полного отчёта в JSON:

    python -m diag --json report.json

## Что делает

- Собирает: ОС, CPU/RAM, диски, топ процессов, автозагрузку, ошибки Event Log.
- Применяет детерминированные правила (заполненный диск, высокая RAM и т.д.).
- Опционально — отправляет данные в Claude для человеческого объяснения.

## Чего не делает

- Не меняет реестр, файлы, службы, автозагрузку.
- Не удаляет ничего.
- Не требует прав администратора (часть данных может быть недоступна).
