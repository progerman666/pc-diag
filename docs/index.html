Что показывает

Один отчёт вместо Проводника, Диспетчера задач, Event Viewer и smartctl по отдельности.

Здоровье дисков (SMART)

Износ SSD в процентах, температура, наработка, предсказание отказа, некорректируемые ошибки. То, чего не видно в Проводнике.

Event Log за 24 часа

Ошибки и критические события из журнала Windows с русскими названиями уровней — без копания в Event Viewer.

Сеть без догадок

Шлюз, DNS, пинг и потери пакетов до роутера и до интернета. Сразу понятно: проблема дома или у провайдера.

Система и процессы

CPU, RAM, своп, топ процессов по памяти и нагрузке, остановленные авто-службы, автозагрузка, крупные папки.

Безопасная очистка

TEMP, корзина, кэш pip, эскизы Windows, кэш VSCode. Сначала «Проверить» — сколько освободится, потом «Очистить» с подтверждением.

Окно и консоль

Графический интерфейс для обычных людей и pc-diag-cli.exe для админов: --slow, --json, отчёт в файл.

Как это работает

Три шага, никакой настройки.

Скачайте и запустите

Portable-архив распаковывается в любую папку, установщик ставит ярлыки. Права администратора нужны только для полных SMART-данных.

60 секунд ожидания

Диагностика стартует сама. Программа читает WMI, журнал событий, сеть и SMART — ничего не меняя в системе.

Читаете вывод

Сверху — сводка по важности, ниже — детали и конкретные советы: что сделать и в каком порядке.

Почему это безопасно

Диагностика и очистка разделены: первая ничего не трогает, вторая спрашивает подтверждение.

только чтение

Диагностика read-only

  • Читает реестр, WMI, журнал событий и файлы — не изменяет их
  • Не требует прав администратора (без них часть SMART будет пустой)
  • Работает без интернета: ничего не отправляет на серверы
  • Не устанавливает службы и драйверы
по подтверждению

Очистка под контролем

  • Сначала «Проверить»: видно, сколько места освободится
  • Удаление — только после подтверждения в диалоге
  • Каждое действие пишется в лог fixer_log.jsonl
  • Исходный код открыт: github.com/progerman666/pc-diag

Частые вопросы

Это правда бесплатно?

Да. Проект распространяется по лицензии MIT: пользуйтесь, изучайте, меняйте и используйте в работе, в том числе коммерческой. Платных версий и подписок нет.

Программа что-то меняет в системе?

Диагностика — нет: она только читает. Очистка (TEMP, корзина, кэши) выполняется отдельно, только по кнопке «Очистить» и после подтверждения. Каждое действие попадает в лог, а настройки автозагрузки сохраняются в резервную копию перед изменением.

Нужны ли права администратора?

Для диагностики не обязательны, но без них часть SMART-данных (износ, температура) может остаться пустой — в окне есть кнопка «Запустить как администратор». Для установки в Program Files права нужны, для portable — нет.

Работает без интернета?

Полностью. Сбор данных идёт локально, наружу ничего не уходит. Дополнительное объяснение находок человеческим языком — опция: можно подключить локальную модель Ollama, тогда интернет не нужен вообще.

Почему антивирус иногда ругается?

Сборка сделана PyInstaller и не подписана сертификатом — такие exe часто попадают в «подозрительные». Исходный код открыт, архив можно собрать самостоятельно по инструкции в README, а SmartScreen-предупреждение снимается кнопкой «Подробнее → Выполнить в любом случае».

Чем это отличается от CrystalDiskInfo и Диспетчера задач?

Они показывают отдельные куски картины. pc-diag собирает диск, журнал событий, сеть, службы, автозагрузку и нагрузку в один отчёт, прогоняет по правилам и выдаёт список проблем с приоритетом и конкретными действиями.

Будет версия для Linux или macOS?

Нет. Инструмент построен на Windows-специфичных API: WMI, журнал событий, Get-PhysicalDisk и smartctl. Под другие платформы это пришлось бы писать заново.

Как удалить программу?

Если ставили установщиком — «Приложения» → pc-diag → Удалить. Portable-версия удаляется вместе с папкой. Службы и драйверы программа не устанавливает, следов в системе не оставляет (кроме собственных логов очистки).
